Skyline Courier is a small original 2D flight game: fly a yellow courier plane down a river valley, thread eight golden rings, then bring her home onto runway 27 before the fuel runs out.

The game is plain Canvas 2D and vanilla JavaScript with no libraries and no network requests: open game/index.html in desktop Chrome and it just plays, keyboard and mouse included.

Throttle and pitch are the whole skill. Full throttle everywhere burns the tank dry, a steep dive builds speed you cannot bleed off, and a hard arrival bends the airframe, so every landing is a decision about gear, flaps, speed and sink rate.

Two missions run back to back. First comes the ring run along the valley, then the landing itself, with a score bonus for the fuel you bring home.

The valley is drawn fresh from numbers every frame: rolling hills, a winding river, pine trees, little red-roofed houses, drifting clouds and a windsock by the runway, all of it original art made in code.

## Run it

```sh
open game/index.html
```
